水塘采样（Reservoir Sampling）用于从长度未知或无法一次载入内存的数据流中，**只遍历一次，等概率地抽取 $k$ 个元素**。

它保证的是最终选出的**集合无偏**。但标准 Algorithm R 直接返回的 reservoir 数组并不是均匀随机排列：最先进入水塘的 $k$ 个元素与初始槽位绑定，因此来源顺序和输出位置之间可能存在相关性。

## 标准算法

```text
ReservoirSampling(stream, k):
    reservoir = 空数组

    for i = 0, 1, 2, ...:
        item = stream[i]

        if i < k:
            reservoir[i] = item
        else:
            j = RandomInteger(0, i)  // 两端都包含
            if j < k:
                reservoir[j] = item

    return reservoir
```

处理第 $i+1$ 个元素时，它入选的概率是：

$$
P(\mathrm{selected})=\frac{k}{i+1}
$$

每个新元素只随机一次，最多替换一个槽位，因此这是无放回采样。同一元素不会同时出现在多个槽位，但同一个槽位可以先后被不同元素替换。

## 为什么每个元素的入选概率相同

假设数据流最终有 $n$ 个元素，水塘容量为 $k$。

对于前 $k$ 个元素，它们一开始就在水塘中。要一直留到最后，需要躲过后续每一次替换：

$$
\frac{k}{k+1}\times\frac{k+1}{k+2}\times\cdots\times\frac{n-1}{n}
=\frac{k}{n}
$$

对于第 $i$ 个元素，它先以 $k/i$ 的概率进入水塘，再躲过后续替换：

$$
\frac{k}{i}\times\frac{i}{i+1}\times\cdots\times\frac{n-1}{n}
=\frac{k}{n}
$$

所以每个元素最终入选的概率都是 $k/n$，所有大小为 $k$ 的子集也等概率。

## 入选无偏，不代表位置无偏

考虑：

```text
stream = [1, 2, 3, 4, 5]
k = 3
```

初始化后：

```text
slot 0  slot 1  slot 2
   1       2       3
```

已有元素只可能留在原槽位或被替换，不会移动到其他槽位。因此元素 `3` 的最终位置分布为：

| 最终状态 | 概率 |
|---|---:|
| `3` 在 slot 0 | $0$ |
| `3` 在 slot 1 | $0$ |
| `3` 在 slot 2 | $\frac{3}{4}\times\frac{4}{5}=\frac{3}{5}$ |
| `3` 被淘汰 | $\frac{2}{5}$ |

`3` 牺牲了出现在其他槽位的可能性，但没有损失总入选概率；它的全部入选概率都集中在 `slot 2`。

## 从一个槽位的视角看

最终 `slot 0` 里可能是谁？

| slot 0 的最终元素 | 概率 |
|---|---:|
| `1` | $\frac{3}{5}$ |
| `2` | $0$ |
| `3` | $0$ |
| `4` | $\frac{1}{5}$ |
| `5` | $\frac{1}{5}$ |

推导如下：

- `1` 必须躲过 `4` 和 `5` 对 slot 0 的替换，概率为 $\frac34\times\frac45=\frac35$。
- `4` 必须先以 $\frac14$ 的概率替换 slot 0，再以 $\frac45$ 的概率躲过 `5`，最终概率为 $\frac15$。
- `5` 处理时必须从五个选择中恰好抽到 slot 0，概率为 $\frac15$。

因此三个槽位分别满足：

```text
slot 0: 1 占 3/5，4 占 1/5，5 占 1/5
slot 1: 2 占 3/5，4 占 1/5，5 占 1/5
slot 2: 3 占 3/5，4 占 1/5，5 占 1/5
```

这里清楚地体现了位置偏置：前 $k$ 个元素分别绑定自己的初始槽位；第 $k$ 个之后的元素出现在任一指定槽位的概率才是 $1/n$。

## 什么时候位置偏置会成为问题

如果下游使用全部 $k$ 个元素，并且处理逻辑与数组位置无关，那么位置偏置不影响采样集合的正确性。

如果下游存在以下行为，位置偏置就可能转化为实际偏差：

- 只使用 reservoir 的前几个元素；
- 按顺序处理，达到 CPU 或时间预算后提前停止；
- 越靠前的元素具有越高权重。

这时可以在采样结束后，对 $k$ 个结果执行一次 Fisher–Yates shuffle：

```text
reservoir = ReservoirSampling(stream, k)
Shuffle(reservoir)
return reservoir
```

额外时间复杂度为 $O(k)$。打乱不会改变入选集合，却能让每个已入选元素等概率落在任一输出位置。

## 总结

- 水塘采样的时间复杂度为 $O(n)$，空间复杂度为 $O(k)$。
- 每个 candidate 的最终入选概率都是 $k/n$。
- 一个 candidate 最多替换一个槽位，不会产生重复元素。
- 标准 Algorithm R 的原始输出存在槽位偏置，尤其是前 $k$ 个元素与初始槽位绑定。
- 如果下游对位置敏感，在采样完成后额外 shuffle 一次。
